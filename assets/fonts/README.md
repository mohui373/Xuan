# 本站字体

Source Sans 3、Source Serif 4 和 IBM Plex Mono 的 Latin WOFF2 文件来自 Fontsource 5.2.5，随附各自的 SIL Open Font License。字体由本站提供，中文采用设备上的中文字体。

字体声明在 [local-fonts.css](../css/local-fonts.css)，字体分工在 [\_site.scss](../../_sass/_site.scss)。更改网站 baseurl 时，也要同步调整 [\_config_xuan.yml](../../_config_xuan.yml) 中的字体样式表地址。

头像展示使用 `assets/img/profile-bole.webp`，原始 JPG 保留作源文件。更换头像时，同步更新中英文页面的尺寸声明，保持实际比例。
