# 旧版学术主页参考快照

本目录保存从 `mohui373/mohui373.github.io` 迁移来的**个人化内容参考**，用于在 `mohui373/Xuan` 中重新设计和建立一套新的申博学术主页。

## 来源

- 旧仓库：`https://github.com/mohui373/mohui373.github.io`
- 旧站点：`https://mohui373.github.io`
- 新仓库：`https://github.com/mohui373/Xuan`

## 迁移原则

这里不把旧站整个模板、工作流和历史包袱直接覆盖到新仓库根目录，而是先保存最重要的个人内容与结构，作为新版设计的事实来源与参考。

这样做的好处是：

1. `Xuan` 根目录仍保持干净的 al-folio 基线；
2. 新版可以重新设计，而不是被旧版 CSS 和页面结构绑住；
3. 研究、论文、CV 与项目事实可以直接复用；
4. 旧站仍可继续在线，方便对照视觉效果；
5. 后续确认新版后，再把 `reference/` 中需要的内容正式迁入 `_data/`、`_pages/`、`_bibliography/` 等位置。

## 新版重建建议

新版优先保持以下导航：

`首页 | 研究 | 论文 | 项目 | 简历`

第一阶段先完成中文版，并继续保留英文版结构。

新版应以博士申请为核心，突出：

- Research identity
- 三条研究主线
- Publications / manuscripts
- `paper-to-paradigm`
- 方法能力
- 可下载 CV

而不是简单复制旧版视觉。

> 注意：头像等二进制图片暂未复制到本参考目录；新版可直接重新上传高清头像。旧站视觉样式可继续通过 `https://mohui373.github.io` 对照。
